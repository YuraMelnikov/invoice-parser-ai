# Шаблон постановки задачи ИИ-агенту

Копируй этот шаблон при постановке любой задачи по проекту. Чем точнее scope
и DoD, тем меньше «агент сделал не то». Правила проекта агент уже знает из
`AGENTS.md` — здесь только специфика задачи.

- [ ] …

## Откат

_(как вернуться к состоянию до задачи, если что-то пошло не так)_

---

### Мини-пример (условный)

**Цель:** добавить healthcheck сервису X в docker-compose.
**Scope:** `docker-compose.yml`.
**DoD:** `docker compose config --quiet` молчит; `docker compose ps` показывает
`(healthy)` через 30 с после старта.
**Откат:** `git checkout docker-compose.yml`.

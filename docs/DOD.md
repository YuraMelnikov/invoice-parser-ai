## End-to-end / eval проверка

Эталонные документы и ожидаемые результаты лежат в репозитории:

```
tests/fixtures/<имя>.pdf              # эталонный скан
tests/fixtures/<имя>.expected.json    # ожидаемый результат (источник истины)
```

Правила eval'а — в `tests/README.md`. Ключевое: агент не правит `expected.json`
(это делает владелец)

# Оператор склада

n8n-решение автоматической обработки приходных накладных в виде PDF-сканов
без текстового слоя.

## Структура репозитория

```
AGENTS.md             # правила проекта для ИИ-агента (единый источник истины)
CLAUDE.md             # ссылка на AGENTS.md
README.md             # этот файл: цель, статус, decision log
RUNBOOK.md            # развёртывание и эксплуатация (проверено на живом хосте 2026-10-06)
docker-compose.yml    # стек этапа 1: postgres, n8n, ollama, qdrant, pgadmin, pdf-render
.env                  # переменные окружения (секреты, не в git)
shared/               # общий том n8n
  pdf-render/          # sidecar-сервис рендера PDF в PNG (app.py + Dockerfile)
sql/
  001_schema.sql      # схема docs.* (идемпотентна; автонакат при первом старте)
  002_archived_at.sql # колонки пайплайна (archived_at, file_mtime; ADR-0002)
workflows/            # n8n-workflow пайплайна (ADR-0002): dispatcher, worker, archive
docs/
  tasks/              # постановки задач по шаблону (001-docker-stack.md и далее)
  decisions/          # ADR — долгая память проекта
tests/
  README.md           # конвенции eval-проверок
  fixtures/           # эталонные PDF + expected JSON (источник истины)
tmp/                  # папка для хранения служебных и/или временных файлов которые создает ИИ
```
